# 🚀 Tech Pulse – Skills Demand & Workforce Intelligence Dashboard

**Tech Pulse** is an interactive data analytics dashboard that analyzes job-market trends, skills demand, job roles, salaries, experience requirements, and company-wise opportunities.

The project transforms job-market data into meaningful insights using Python, Pandas, Plotly, and Streamlit.

## 🎯 Objectives

* Analyze job-market trends.
* Identify in-demand technical skills.
* Compare different job roles.
* Analyze salary patterns.
* Study the relationship between experience and salary.
* Provide an interactive workforce intelligence dashboard.

## ✨ Features

* 🏙️ City-wise job demand
* 🔥 Top skills analysis
* 👩‍💻 Job role distribution
* 💰 Salary analysis
* 📈 Experience vs Salary analysis
* 🏢 Company-wise salary analysis
* 🔎 Interactive filters
* 📥 Filtered data download

## ▶️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/khushijain290105-ux/Tech-Pulse.git
```

### 2. Open the project

```bash
cd Tech-Pulse
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Streamlit dashboard

```bash
streamlit run app.py
```
